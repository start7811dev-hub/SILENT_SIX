# 변경 기록

## v0.33.1 (2026-11-21) 아이폰 BGM 수정, 오프닝부터 BGM
- **아이폰에서 BGM이 다이내믹 아일랜드의 시스템 재생기에 뜨고 소리는 안 나던 문제를 고쳤다.** BGM을 `<audio>` 요소로 틀어 Web Audio에 물리던 방식이 원인이다(아이폰 사파리에서 이 조합은 재생 표시만 뜨고 소리가 안 나는 일이 있다). `<audio>`를 없애고, 파일을 받아 풀어서 Web Audio 버퍼로 직접 튼다. 시스템 재생기에 올라갈 요소가 없다.
- 설정 > 사운드에 "무음 모드에서도 소리"를 추가했다(아이폰 사파리처럼 지원하는 기기에서만 보인다, 기본 ON). 아이폰은 Web Audio를 무음 스위치로 묻어 버리는데, 켜 두면 무음에서도 난다. 대신 다른 앱의 음악은 멈춘다. 끄면 무음 스위치를 따른다.
- **오프닝부터 BGM이 나오고 홈까지 끊기지 않고 이어진다.** 브라우저는 첫 터치 전에 소리를 못 내므로, 오프닝이 자동 재생되는 날에는 `TOUCH TO START` 화면을 먼저 띄운다. 처음 온 날은 오프닝 선택이 그 터치다. 소리가 다 꺼져 있으면 이 화면은 건너뛴다.
- 세션의 첫 곡은 메인 테마(`base_1` NO RECORD)다. 시작할 때 미리 받아 두어 터치와 함께 바로 나온다. 다음 곡은 끝나기 25초 전에 미리 받는다.
- 소리 잠금 해제를 보강했다: 멈춤 · 중단 상태의 오디오를 터치마다 다시 깨우고, 첫 터치에 무음 한 샘플을 틀어 연다.
- 점검: `tools/verify.sh` 29판 전부 OK. 크롬(375px)에서 시작 화면 → 오프닝 → 홈 연속 재생, 다음 곡, 풀 전환, 곡 끝 겹침, 끄고 켜기, 화면 이탈을 확인했다. **아이폰 실기 확인은 아직이다.**

## v0.33.0 (2026-11-21) BGM, 홈 HUD 난이도 · BGM 토글
- BGM 재생 엔진. 풀별 랜덤: 공용 5곡(홈 · 메뉴 · 스토리), 로맨틱 3, 코스튬 3, 블러디 크리스마스 3. 풀을 한 바퀴 돌기 전에는 같은 곡이 다시 나오지 않고, 곡 끝 2.5초를 다음 곡과 겹쳐 넘긴다.
- 로맨틱 · 블러디 크리스마스는 브리핑에 들어가면 전용 풀로, 메뉴로 나오면 공용 풀로 넘어간다. 코스튬 풀은 미션 데이터에 `costume:true`가 붙으면 나온다(코스튬 엔진 구현 때 붙인다).
- 음원 14곡을 넣었다(`public/bgm/<이름>.mp3`, 128 kbps, 합계 34 MB). 일레븐랩스에서 뽑은 원본의 앞뒤 무음을 자르고 음량을 맞췄다. 없는 곡은 건너뛰고, 전용 풀이 통째로 없으면 공용 풀로, 공용도 없으면 소리 없이 돈다. 프롬프트와 원본 대응표는 `docs/BGM.md`.
- 가사가 있는 테마송(NO RECORD, OFF THE RECORD)은 넣지 않았다.
- `tools/bgm/prep.sh`: 받은 음원의 앞뒤 무음을 자르고, 곡 전체를 같은 폭으로 조정해 음량을 -18 LUFS로 맞춘 뒤 `public/bgm/`에 넣는다.
- 홈 HUD 둘째 줄 추가: 난이도 칩(누르면 4단계 목록이 설명 · 점수 배수와 함께 열리고, 고르면 바로 적용), `BGM ON/OFF` 토글. 첫 줄에 있던 난이도 표시는 이 칩으로 옮겼다.
- 설정 > 사운드: BGM 켜기(지금 나오는 곡 표시), BGM 음량, 미션 전용 BGM 켜기, 다음 곡, 효과음 음량(기존 "음량").
- 소리 잠금 해제를 `pointerdown` 한 가지에서 `pointerup` · `touchend` · `click` · `keydown`까지 넓혔다.
- 점검: `tools/verify.sh` 29판 전부 OK. 크롬(375px)에서 실제 음원으로 재생 · 다음 곡 · 풀 전환(공용 ↔ 블러디 ↔ 로맨틱)을, 시험 음원으로 곡 끝 겹침 · 파일 없음 · 화면 이탈을 확인했다. **아이폰 사파리 실기 확인은 아직이다.**

- 스페셜 미션에 요원별 프리퀄 6편의 자리를 잡았다(줄거리는 docs/STORY.md).
- 관리자: 설정 → 관리자 → 코드 입력. 구역(개인·시즈널·스페셜·그날 밤 이미지)과 미션별 공개/비공개, 미션별 대표 이미지를 바꾼다. 결과는 config.json으로 내려받아 public에 올리면 모든 사용자에게 적용된다. 코드는 저장소에 없고 해시만 있다.
- 이미지 생성기에 세트를 추가했다: 개인 미션 확장, 미션 키비주얼, 겨울 착장, 코스튬, 프리퀄 장면, 맵 다시 그리기.

알려진 것
- 관리자 보안은 정적 사이트의 한계 안에 있다. 비공개로 돌려도 파일 주소를 아는 사람은 이미지를 받을 수 있다. 서버 인증으로 옮길 때까지는 민감한 파일을 저장소에 두지 않는 것이 유일한 방법이다.
- 겨울 맵은 기존 맵의 색을 바꾼 것이다.

## v0.11.0 — 2026-11-17
새 요원 이미지와 스토리 정리.

- 요원 이미지 54장 교체(요원당 포즈 8컷 + 그날 밤 1컷, 768×1152). 게임 내 요원 스프라이트 6종 교체. 닥의 임시 스프라이트가 정식으로 바뀌었다.
- 오프닝 두 버전을 다시 만들었다. DAY-OFF는 운동 컷, MISSION은 전투 컷. 컷마다 감속으로 들어와 가속으로 나가는 카메라. 요원 이름과 한 줄 대사. 마지막은 쓰인 6장을 세로 띠로 세우고 문구로 끝난다.
- 세계관과 시즌 1 줄거리를 정리했다(docs/STORY.md). 메인 미션 6판의 시작·끝 문구를 "팔린 명단을 따라간다"는 줄기에 맞춰 고쳤다. 시즌 선택 화면에 세계관 세 줄이 나온다.
- 미션 시작 화면을 새로 만들었다. 그 판에 들어가는 요원을 크게 보여 주고, 목표와 배지 조건, 미션 시작 버튼만 둔다.
- 플레이 설명은 TIP으로 옮겼다. 미션 중 화면 위 TIP 버튼(누르면 멈춘다)과 미션 시작 화면에서 볼 수 있다.
- 이미지 규칙: 메인 미션은 도발·전투 컷, 개인 미션은 섹시 컷(잠겨 있으면 흐리게), 시즈널·스페셜 타일은 섹시와 그날 밤을 뺀 무작위.

알려진 것
- 하단 요원 카드의 얼굴 그림은 예전 그림 그대로다.
- 미션 6 맵은 여전히 임시 그림이다.
