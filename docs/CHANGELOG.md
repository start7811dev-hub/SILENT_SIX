- 로맨틱 · 블러디 크리스마스는 브리핑에 들어가면 전용 풀로, 메뉴로 나오면 공용 풀로 넘어간다. 코스튬 풀은 미션 데이터에 `costume:true`가 붙으면 나온다(코스튬 엔진 구현 때 붙인다).

- 가사가 있는 테마송(NO RECORD, OFF THE RECORD)은 넣지 않았다.
- `tools/bgm/prep.sh`: 받은 음원의 앞뒤 무음을 자르고, 곡 전체를 같은 폭으로 조정해 음량을 -18 LUFS로 맞춘 뒤 `public/bgm/`에 넣는다.
- 홈 HUD 둘째 줄 추가: 난이도 칩(누르면 4단계 목록이 설명 · 점수 배수와 함께 열리고, 고르면 바로 적용), `BGM ON/OFF` 토글. 첫 줄에 있던 난이도 표시는 이 칩으로 옮겼다.
- 설정 > 사운드: BGM 켜기(지금 나오는 곡 표시), BGM 음량, 미션 전용 BGM 켜기, 다음 곡, 효과음 음량(기존 "음량").
- 소리 잠금 해제를 `pointerdown` 한 가지에서 `pointerup` · `touchend` · `click` · `keydown`까지 넓혔다.
- 점검: `tools/verify.sh` 29판 전부 OK. 크롬(375px)에서 실제 음원으로 재생 · 다음 곡 · 풀 전환(공용 ↔ 블러디 ↔ 로맨틱)을, 시험 음원으로 곡 끝 겹침 · 파일 없음 · 화면 이탈을 확인했다. **아이폰 사파리 실기 확인은 아직이다.**

- 플레이 설명은 TIP으로 옮겼다. 미션 중 화면 위 TIP 버튼(누르면 멈춘다)과 미션 시작 화면에서 볼 수 있다.
- 이미지 규칙: 메인 미션은 도발·전투 컷, 개인 미션은 섹시 컷(잠겨 있으면 흐리게), 시즈널·스페셜 타일은 섹시와 그날 밤을 뺀 무작위.

알려진 것
- 하단 요원 카드의 얼굴 그림은 예전 그림 그대로다.
- 미션 6 맵은 여전히 임시 그림이다.
