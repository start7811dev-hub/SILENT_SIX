SILENT SIX Studio — 요원 풀세트 생성기 (맥용)

실행
1. 이 폴더를 원하는 곳에 둔다.
2. "SILENT6 Studio.command"를 더블클릭한다.
   - "열 수 없음" 경고가 뜨면: 파일을 우클릭 → 열기 → 열기.
   - 그래도 안 되면 터미널에서:  cd 이폴더경로  &&  python3 silent6_studio.py
3. 브라우저가 열리면 API 키를 넣고, 요원을 고르고, 기존 일러스트 시트를 끌어다 놓고, "선택한 컷 생성"을 누른다.

결과
- 바탕화면/SILENT6_output/요원이름/ 에 PNG로 저장된다.
  raven_1 ~ raven_8 (포즈 8컷), raven_end (엔딩 컷), s_raven (게임 내 스프라이트 시트)
- "이 요원 ZIP 만들기"를 누르면 한 파일로 묶인다. 그 ZIP을 Claude에 올리면 게임에 넣는다.

참고
- 추가 설치는 없다. 맥에 python3만 있으면 된다(없으면 터미널에서 xcode-select --install).
- 끝낼 때는 터미널 창에서 Ctrl+C.
- 모델 칸은 직접 고칠 수 있다. 계정에서 쓸 수 있는 이미지 모델 이름을 넣으면 된다.
