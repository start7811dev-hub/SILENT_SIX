# 그림에서 충돌 맵 따기 (S1-06 격리 병동)

그림을 먼저 받고, 그림을 분석해 격자 · 벽 · 가구를 정한 기록이다. 다른 맵에도 같은 순서로 쓴다.

1. `g.py` — 바닥 네 모서리로 투영(호모그래피)을 구한다. 칸은 약 1m(화면에서 한 변 40px 안팎).
2. `seg.py` — 벽 윗면 중심선을 화면 좌표로 찍고, 벽 높이만큼 내려 바닥 좌표로 바꾼다.
3. `mk.py` — 중심선을 칸으로 채우고 그림 위에 겹쳐 확인한다.
4. `fin.py` — 가구 · 목표 · 카메라 칸을 더해 최종 MAP 을 낸다.

원본 그림 경로는 스크립트 안에 `src.png` 로 적혀 있다(`public/bg6.jpg` 를 복사해 쓴다).
