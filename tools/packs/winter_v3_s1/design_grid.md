# 1판 타일 설계 메모 2차 (Claude 작업용, zip 에 넣지 않는다)

격자 30x30, 1칸 = 1 m, 벽 포함. 안쪽 28칸 = 골목2 / 블록5 / 골목2 / 광장10 / 골목2 / 블록5 / 골목2.
- 문: 네 벽 중앙. 진입은 왼쪽 아래 벽.
- 블록 12개: 모서리 4(5x5) + 변마다 2(5x4, 사이에 큰길 2칸).
- TOP 회전목마 / RIGHT 발전기 마당 / BOTTOM 분수 / LEFT 빵집.
- 오른쪽 아래 변: 무대 + 가판대 묶음. 왼쪽 위 변: 가판대 묶음 2. 오른쪽 위 변: 가판대 묶음 + 장난감 가게. 왼쪽 아래 변: 집 2.
- 광장: 트리 울타리 5x5, 문은 오른쪽 위. 광장 네 귀퉁이에 가판대 1채씩.
길: 바깥 골목(어둡고 김) / 큰길 4(밝고 경비) / 샛골목 8. 엄폐물은 낱개 이미지로 골목 2~4칸마다.
경비 8~10명. 매듭: 트리 문 양옆 고정 2, 무대 앞 2인조, 바깥 골목 순찰 2, 사복 3(무전 1).
