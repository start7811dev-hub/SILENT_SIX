# 1판 타일 설계 메모 (Claude 작업용, zip 에 넣지 않는다)

격자 21x21, 1칸 = 1 m. x 는 오른쪽 아래, y 는 왼쪽 아래로 증가. (0,0)=TOP.
벽: x=0 왼쪽 위, y=0 오른쪽 위, x=20 오른쪽 아래, y=20 왼쪽 아래.

- 문: (10,20) 진입, (20,10) 무대 뒤, (10,0) 산책로, (0,10) 뒷골목
- 진입 마당: x 8..12, y 16..19
- 가림 줄: y=15, 가판대 x 4-6 / 8-9 / 11-12 / 14-16, 틈 x=7, 10, 13
- 트리 울타리: x 7..11, y 8..12, 문 (9,8), 상자 (9,9)
- 가판대 구역: 바깥 줄 x=2 (y 4-6, 8-10, 12-14), 안쪽 줄 x=4 (y 5-7, 9-11, 13-14), 뒷골목 x=1
- 무대: x 16..17, y 8..13 / 광장 x 12..15, y 7..14 / 무대 뒤 통로 x 18..19, y 7..15
- 발전기: (18..19, 5..6)
- 회전목마 울타리: x 2..6, y 1..5 / 분수: x 13..16, y 1..4 / 산책로 x 7..12, y 1..7

길 3개: 왼쪽 틈 -> 가판대 구역 -> 회전목마 아래 (길고 안전) / 오른쪽 틈 -> 무대 뒤 통로 -> 발전기 (짧고 경비 2명이 마주 봄) / 가운데 틈 -> 광장 횡단 (미라주 변장 전용).
매듭: 울타리 문 양옆 고정 경비 2명, 무대 뒤 통로 양 끝 2명.
