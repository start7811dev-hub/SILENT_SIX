## INSTRUCTIONS FOR THE IMAGE MODEL

You are painting **separate object sprites** that will be placed on top of the map `bgw1_v3.jpg` (or `ref/look_take1.png` if that map is not in this conversation). They must look cut out of that same painting: **same 2:1 isometric camera, same painterly finish, same snow, same warm-lamp and cool-ambient lighting**.

Make **four sheets, one image per reply**. Write the output file name on its own line before the image. After each sheet, stop and wait for "next". Do not ask questions.

### Rules for every sheet
1. Exactly **1536x1024**. The sheet is an invisible grid of **3 columns x 2 rows**, each cell 512x512. **One object per cell, centred**, filling about 70% of the cell, with clear empty margin on all sides. Objects never touch or overlap a neighbouring cell.
2. **Transparent background** (PNG). If you cannot output transparency, use flat pure magenta `#FF00FF` everywhere behind the objects.
3. **No ground, no floor tile, no cast shadow, no glow spilling onto the background.** Only the object itself.
4. Same camera for every object: 2:1 isometric, seen from above at the same angle as the map. Every object stands on an invisible rectangular footprint aligned to the two isometric axes.
5. Keep relative scale between cells honest: a 1 m crate is about a third as long as a 3 m sleigh.
6. A thin cap of snow on top surfaces. No text, numbers, logos, people, labels, cell borders or watermark.
7. "Orientation 1" means the long side runs toward the lower-right. "Orientation 2" means the same object with its long side running toward the lower-left.
