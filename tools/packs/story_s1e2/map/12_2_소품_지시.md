## INSTRUCTIONS FOR THE IMAGE MODEL

You are painting **separate object sprites** that will be placed on top of the map `bg_s1_12.jpg`. They must look cut out of that same painting: same 2:1 isometric camera, same painterly finish and lighting.

Make **two sheets, one image per reply**. Write the output file name on its own line before the image. After the first sheet, stop and wait for "next". Do not ask questions.

### Rules for every sheet
1. Exactly **1536x1024**, an invisible grid of **3 columns x 2 rows** (512x512 cells). One object per cell, centred, about 70% of the cell, clear margins.
2. **Transparent background** (PNG). If not possible, flat pure magenta `#FF00FF` behind the objects.
3. No ground, no floor tile, no cast shadow, no glow spilling onto the background.
4. Every object stands on an invisible rectangular footprint of **whole metres**, aligned to the two isometric axes, at the same camera as the map. Keep relative scale honest between cells.
5. "Orientation 1": long side runs toward the lower-right. "Orientation 2": long side runs toward the lower-left.
6. No text, numbers, logos, emblems, people, labels, cell borders or watermark.
