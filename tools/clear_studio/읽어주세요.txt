SILENT SIX Clear Studio — 미션 클리어 이미지 생성기

1. "SILENT6 Clear Studio.command"를 더블클릭한다. (처음에는 우클릭 > 열기)
2. 브라우저가 열리면 OpenAI API 키를 넣는다. 키는 이 맥의 브라우저에만 저장된다.
3. 왼쪽에서 미션을 고르고 "이 미션 4장 생성" 또는 단계별 "생성"을 누른다.
4. 결과는 ~/Desktop/SILENT6_output/clear/ 에 r_미션키_번호.jpg 로 저장된다.
   번호: 0 클리어(모든 난이도) / 1 전투 / 2 도발 / 3 고자극 (HARD 이상 한 판에서 딴 배지 1 / 2 / 3개)
5. 그 JPG를 저장소 public 폴더에 올리면 게임 결과 화면과 블랙박스에 바로 붙는다.

- 등장 요원이 2명 이상이면 참조 이미지를 요원 수만큼 함께 보내고, 전원이 한 장면에 나오도록 지시한다.
- 참조 이미지는 저장소의 public/a_요원_0.jpg 를 자동으로 쓴다. 이 폴더만 따로 옮겨 쓸 때는 요원 칸을 Option+클릭해서 파일을 지정한다.
- 미션 정의(장소, 등장 요원, 단계별 장면)는 화면에서 고치고 "미션 정의 저장"을 누르면 missions.json 에 남는다. 이전 내용은 missions.json.bak.
- 왼쪽 '묶음'에서 스토리 / 로맨틱 / 시즈널 / 코스튬을 고른다. 묶음마다 분위기 지침과 단계별 연출 지시가 따로 있다.
- 미션의 장면 칸을 비워 두면 미션 요약 + 묶음의 단계 지시로 프롬프트를 만든다.
- 새 미션은 "+ 미션 추가". 미션 키는 게임의 키와 같아야 한다(예: S1-01, W-1, P-raven-1).
- 수위 문구(성인 여성, 노출·성행위 없음)는 모든 프롬프트 끝에 고정으로 붙는다.
