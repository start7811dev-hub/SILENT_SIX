# A. 클리어 이미지 (스테이지 5개 × 4장)

새 채팅에 **공통 지시**를 먼저 붙여 넣고, 스테이지 블록 하나와 등장 요원의 참조 이미지를 함께 보낸다. 5판은 요원이 3명이다.

## 공통 지시

```
You are producing key art for a game. For every mission block I send, create 4 separate images, one after another in the same reply, as 4 individual image outputs. Never combine them into a grid, collage or contact sheet. Do not ask questions between images.
If you can only produce one image per reply, make image #0 first and continue with the next one each time I say "next".

Format for every image: vertical portrait, 2:3 aspect ratio, 1024x1536. Before each image, write its file name on its own line.

Characters: I attach one reference image per character. Keep each woman exactly as in her reference: same face, hair, build and the same art style. When a block lists two or three characters, all of them must appear together in every image, and none may be merged or dropped.

Style: Semi-realistic anime illustration, cinematic lighting, rich detail, the same art style as the reference images. Vertical 2:3 composition. Every face fully visible and unobstructed, heads in the upper half of the frame with clear space above the hair. No text, no logo, no watermark.

All characters are adult women in their late twenties. Sensual and glamorous is fine, but everyone stays fully covered: no nudity, no exposed nipples or genitals, no sexual acts.
```
